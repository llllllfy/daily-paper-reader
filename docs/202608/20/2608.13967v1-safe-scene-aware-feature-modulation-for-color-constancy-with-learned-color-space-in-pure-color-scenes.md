## 摘要
纯色场景中的颜色恒常性具有挑战性：当大多数像素共享较窄的色调范围时，所有基于色度的线索都会坍缩到一个点，标准估计方法变得模棱两可。我们提出一个紧凑的框架，结合两项创新：（i）SAFE，一种场景感知特征调制网络，将光照线索组织为结构化的四 token 表示，然后根据场景复杂度特征进行选择性重加权；（ii）学习颜色空间（LCS），一种场景相关的色度归一化方法，直接解决纯色场景中的色度坍缩问题。实验结果表明，SAFE 在纯色场景中持续提升性能。与各指标上表现最佳的基线相比，平均角度误差降低10%，最佳25%误差降低20%，最差25%误差降低5.8%。

## Abstract
Color constancy on pure-color scenes is challenging: when most pixels share a narrow band of hues, every chromaticity-based cue collapses to a single point and standard estimators become ambiguous. We propose a compact framework that couples two innovations: (i) SAFE, a Scene-Aware FeaturE modulation network that organizes illumination cues into a structured four-token representation, which is then selectively reweighted based on scene complexity features; (ii) the Learned Color Space (LCS), a scene-dependent chromaticity normalization that directly addresses the chromaticity collapse problem for pure-color scenes. Experiment results show that SAFE consistently improves performance in pure-color scenes. Compared to the best-performing baseline in each metric, it reduces the mean angular error by 10%, the best-25% error by 20%, and the worst-25% error by 5.8%.

# SAFE 论文结构化总结

## 1. 论文的核心问题与整体含义

- 论文聚焦**纯色场景（pure-color scenes）中的颜色恒常性（color constancy）**问题。
- 在纯色或近单色场景中（如微距摄影、特写人像、海洋/天空/雪地、舞台灯光），大多数像素共享很窄的色调范围。
- 这会导致所有基于色度（chromaticity）的光照线索都坍缩到一个点，传统统计方法和基于学习的方法都难以区分“白光照在红表面”与“红光照射白表面”，估计结果高度模糊。
- 现有方法通常在颜色多样性丰富的数据集上训练，在纯色场景上表现不佳。因此本文旨在提出一种针对纯色场景的、轻量且可解释的颜色恒常性框架。

## 2. 论文提出的方法论

论文提出 **SAFE（Scene-Aware Feature Modulation）** 框架，并结合 **LCS（Learned Color Space）**，核心包括三个部分：

### 2.1 特征提取

- **场景复杂度特征（8D）**：包括色度熵 \(H\)、PCA方差比 \(\pi\)、色度标准差 \(\sigma_r,\sigma_g\)，以及色度均值/最大值等；前4维为“color-blind”子集，用于驱动调制门控，后4维为“color-aware”扩展，用于LCS预测。
- **光照相关特征（24D，四个token）**：
  - **Token A（8D）**：原图中最大、均值、最亮、最暗像素的色度坐标。
  - **Token B（8D）**：Sobel边缘图上同样四类代表性色度。
  - **Token C（6D）**：镜面高光对数色度比（\(\log(R/G+\epsilon), \log(B/G+\epsilon)\)）和原图/边缘图的色度分散度。
  - **Token D（2D）**：基于二色反射模型的主方向，由平方亮度加权的色度PCA得到。

### 2.2 场景感知特征调制网络（SAFE backbone）

- 用场景复杂度子集 \(g\in\mathbb{R}^4\) 通过两层MLP + sigmoid生成24D乘法注意力掩码 \(\alpha(g)\)。
- 对光照特征 \(f_{\text{illum}}\) 进行逐元素加权得到 \(f_m = \alpha(g) \odot f_{\text{illum}}\)。
- 将 \(f_m\) 与 \(g\) 拼接后送入残差MLP骨干，输出3D光照估计 \(\hat{y}\)。

### 2.3 学习颜色空间（LCS）

- 标准色度归一化使用均匀权重 \((R,G,B)/(R+G+B)\)，在纯色场景下会失效。
- LCS引入可学习的通道权重 \(w=(w_R,w_G,w_B)\)，定义广义色度：
  \[
  r_w(p)=\frac{w_R R_p}{w_R R_p+w_G G_p+w_B B_p}, \quad g_w(p)=\frac{w_G G_p}{w_R R_p+w_G G_p+w_B B_p}
  \]
- 由一个轻量CNN+MLP预测器 \(\psi\) 根据图像低分辨率摘要和场景复杂度特征 \(\rho\) 输出 logit 残差，再通过 softmax 得到 \(w(I)\)。

### 2.4 四阶段训练流程

1. **Phase 1**：在角误差损失下预训练 SAFE backbone 和粗略全局 \(w\)-模块。
2. **Phase 2**：冻结 backbone，对每个训练图像用80步 Adam 搜索最优场景相关 \(w\)，作为 LCS 的“天花板”目标。
3. **Phase 3**：训练 LCS 预测器 \(\psi\)，使其模仿 Phase 2 搜索到的 \(w\)。
4. **Phase 4**：联合微调 backbone 和 \(\psi\)，损失为角误差损失 + 预测一致性正则项（对图像加乘性噪声，约束 \(w\) 稳定）。

最终推理时，\(\psi\) 为每张图像输出颜色轴 \(w(I)\)，用于重新参数化色度归一化并计算四-token特征，SAFE backbone据此预测光照。

- SAFE 结合 LCS 在 PolyU Pure Color V2 上取得最佳结果，平均角误差降至 1.94°，中位数 1.27°，最优25%为 0.36°，最差25%为 4.66°。

- 消融实验表明四个 token 和场景路由调制模块均对性能有贡献，其中 Token C（镜面/色散线索）贡献最大，与网络内部权重分析一致。
- 推理成本：SAFE 参数量约 61.5K，延迟 0.66 ms，在精度和效率之间达到较好平衡。

## 7. 优点

- **问题针对性强**：直接解决纯色场景中色度坍缩这一关键挑战。
- **方法设计可解释**：四-token光照特征具有明确物理或统计语义；场景复杂度特征分为 color-blind 和 color-aware 两部分，分别用于门控和 LCS 预测。
- **创新的 LCS**：场景相关色度归一化是一种有效应对纯色场景的新思路，并且通过四阶段训练将“搜索到的最优颜色轴”蒸馏给轻量预测器。
- **轻量高效**：总参数约 61.5K，推理延迟低，适合嵌入式或移动端部署。
- **分析深入**：通过内部权重、注意力掩码、LCS偏差-熵相关性分析验证了设计的合理性和各组件的作用。

## 8. 不足与局限

- **通用场景泛化有限**：虽然论文声称在 Gehler-Shi 上“comparable”，但 SAFE 明显不如 C4、CLCC、GCC 等通用场景SOTA方法，说明其优势主要集中在纯色场景。

- **数据集规模较小且单一**：仅在 PolyU Pure Color V2 上验证纯色场景性能，样本量有限，三折交叉验证可能高估泛化性。
