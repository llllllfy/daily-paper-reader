## 摘要
通常通过单个全局图像嵌入来评估冻结的视觉基础模型，但这种接口可能会将缺失信息与读出时丢失的信息混为一谈。我们通过保持预训练视觉编码器冻结不变，仅改变应用于其最终 patch token 的读出方式，来研究这种区别。我们将标准的全局读出与轻量级注视读出（使用学习到的或问题条件化的查询对 patch token 进行注意力池化）以及具有标注目标区域访问权限的 oracle 读出进行比较。我们在三个局部绑定问题上评估这些接口：一个在杂乱背景下的受控合成颜色-形状绑定任务、一个无颜色的拥挤形状检测变体，以及一个源自 GQA 的自然图像任务，其中配对问题询问同一图像中不同同类物体的颜色。当合成目标单独出现时，全局读出近乎完美，但在杂乱和反事实目标编辑下性能崩溃，而注视读出恢复了大部分 oracle 可访问的信号。在源自 GQA 的任务上，与仅问题先验相比，问题无关的全局图像向量仅有适度改进，而问题条件化的注视则显著提高了配对局部颜色准确率。反事实干扰-信号比解释了合成失败的原因：全局池化稀释了局部标签改变证据，同时使探针暴露于来自无关物体的干扰变化中。这些结果表明，冻结视觉模型中明显的空间盲区可能源于全局嵌入接口，而非冻结的 patch token 中缺少空间信息。

## Abstract
Frozen vision foundation models are commonly evaluated through a single global image embedding, but this interface can conflate missing information with information lost at readout time. We study this distinction by keeping a pretrained vision encoder frozen and varying only the readout applied to its final patch tokens. We compare standard global readouts against a lightweight foveated readout, which attention-pools patch tokens using a learned or question-conditioned query, and against an oracle readout with access to the annotated target region. We evaluate these interfaces on three localized binding problems: a controlled synthetic color--shape binding task under clutter, a color-free crowded shape-detection variant, and a GQA-derived natural-image task where paired questions ask for the colors of different same-category objects in the same image. Global readouts perform near perfectly when the synthetic target appears alone, but collapse under clutter and counterfactual target edits, whereas the foveated readout recovers most of the oracle-accessible signal. On the GQA-derived task, question-independent global image vectors improve only modestly over question-only priors, while question-conditioned foveation substantially improves paired localized color accuracy. A counterfactual nuisance-to-signal ratio explains the synthetic failures: global pooling dilutes localized label-changing evidence while exposing the probe to nuisance variation from irrelevant objects. These results indicate that apparent spatial blindness in frozen vision models can arise from the global embedding interface rather than from an absence of spatial information in the frozen patch tokens.

### 1. 论文的核心问题与整体含义

*   **核心问题**：研究冻结视觉基础模型（如 ViT 编码器）在空间关系、属性绑定等局部推理任务上的失败，究竟是因编码器内部**信息缺失**（表征失败），还是因传统的**全局嵌入读出**方式在信息汇聚时丢失了空间信息（读出层空间盲区）。
*   **整体含义**：看似“空间盲”的冻结模型，其底层 patch token 中可能实际保留了丰富的局部绑定信息，仅因全局池化等读出接口不当而被掩盖。该工作将评估焦点从模型表征转移至读出协议，提出一种诊断性分析框架。

### 2. 论文提出的方法论

*   **核心思想**：通过**保持预训练视觉编码器完全冻结**、仅改变作用在最终 patch token 上的**读出机制**，来区分信息缺失与信息读出丢失。如果一种轻量、可学习的读出器能恢复全局读出失败的任务信号，则说明信息原本存在。
*   **关键技术细节与算法流程**：
    *   **基线全局读出**：
        *   `GAP`：对 patch token 做均匀平均池化。
        *   `Summary`：直接使用编码器自身的预训练全局总结 token（如 class token）。
        *   `Question-only`（仅语言任务）：仅输入文本嵌入，衡量纯文本先验。
    *   **注视读出**：一种轻量级、单查询的注意力池化器。
        *   对于视觉任务：学习一个共享查询向量 \(q\)，计算每个 token 的得分（归一化点积），经软最大值（带温度系数）得到注意力权重，再对原始 token 加权求和。
        *   对于视觉-语言任务：查询 \(q(Q)\) 由**冻结文本嵌入**经可学习线性映射生成，温度系数也可学习。**注意力权重无位置监督，仅由任务损失端到端训练**。
    *   **预言机读出**：直接利用标注的目标边界框，仅对目标区域内的 patch token 做平均池化。**作为非部署的上界诊断**，非可部署方法。
    *   **反事实干扰-信号比（NSR）**：直接在读出表征上测量稳定性指标。
        *   **信号**：仅改变标签定义因素（如目标颜色/形状）而保持其他不变时，表征的变化程度。
        *   **干扰**：保持目标不变、仅重采样无关物体的多种场景中，表征的方差。
        *   **NSR = 干扰 / 信号**。值远大于 1 表示表征变化主要由无关变化主导，而非标签变化，可用于量化全局池化稀释局部信号的程度。

### 3. 实验设计

*   **数据集与场景**：
    1.  **合成颜色-形状绑定任务（CSB）**：6 类分类，目标物体颜色-形状组合。背景包含大量匹配部分属性的对抗性诱饵和噪声物体。有纯净（无背景）分片和诊断用反事实对、干扰组。
    2.  **拥挤形状检测任务（CSD）**：无色变体，2 类形状分类，目标尺寸更小，杂波密集。
    3.  **GQA 衍生自然图像局部颜色绑定（GQA*）**：从 GQA 场景图构建，同一图片内两个问题指向**同类别不同实例且不同颜色**，需根据问题定位物体（如“上面那个是什么颜色”）。
*   **基准与对比方法**：
    *   主要对比四种读出：`GAP`、`Summary`、`注视读出`、`预言机读出`。
    *   指标：普通准确率、**配对反事实准确率**（要求原图和编辑目标后的图像同时分类正确）、**配对准确率**（自然图像双问题均答对）、**NSR**。
    *   在三个主流冻结视觉编码器（SigLIP、CLIP、SigLIP 2）和两种分类头（线性、MLP）上验证一致性。

### 6. 论文的主要结论与发现

*   **惊人对比**：在合成任务纯净场景下所有读出器均近 100% 精度；但加入杂波后，全局读出（GAP/Summary）的配对反事实准确率跌至接近随机水平（约 3.5%），而**注视读出达 93.5%，逼近预言机上界（99.3%）**。
*   **NSR 量化证据**：全局读出的 NSR 随杂波数量升高（从 ~7 升至 15），表明杂波引起的表征位移远大于标签改变；而注视和预言机读出的 NSR 始终稳定在 0.3 左右。
*   **自然图像任务**：问题条件化的注视读出使配对准确率达到 17%（全局读出仅约 4%），缩小了约 45% 的与预言机（33%）的差距，证明了相同的问题同样存在于自然图像中。
*   **核心结论**：“冻结视觉模型是否‘空间盲’？”这个问题的答案取决于你用什么接口访问 patch token。**信息可能并未缺失，只是被不恰当的全局读出方式掩盖了。**

### 7. 优点

*   **尖锐的诊断框架**：明确区分“表征缺失”与“读出失效”，提供了反事实 NSR 等可直接计算于表征的量化工具，超越单纯的准确率下降观察。
*   **轻量且严格的实验控制**：注视读出只引入极少的可训练参数，视觉编码器完全冻结，确保性能变化仅源于读出接口改变，而非表征学习。
*   **多维验证**：通过合成（控制变量）到自然图像、多编码器、多探头、线性与 MLP 头的全面实验，使结论高度稳健、普适。
*   **操作简单却有效**：一个单查询的注意力池化即能恢复大量空间信息，表明问题核心不在于复杂机制，而在于信息汇聚的时机。

### 8. 不足与局限

*   **应用场景有限**：注视读出仅作为诊断工具，文中并非声称其是通用的视觉-语言解决架构。它不涉及跨模态深层交互，在生成式多模态模型中价值有限。
*   **自然图像任务绝对性能仍偏低**：GQA* 任务中注视读出仅 17%，距预言机（33%）仍有差距，受限于场景图标注噪声、颜色歧义及配对任务本身的高难度。注视读出未能完全恢复上界。
*   **注视的泛化性未深入测试**：注意力训练依赖特定任务损失，未测试跨任务迁移、零样本条件下的表现。
*   **编码器与层级的局限**：实验仅在视觉编码器最后一层 patch token 进行，未探究中间层信息，也未涵盖更现代的多层视觉-语言模型架构。
