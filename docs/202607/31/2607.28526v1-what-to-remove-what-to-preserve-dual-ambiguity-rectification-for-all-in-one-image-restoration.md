## 摘要
一体化图像复原旨在统一框架内处理多种退化。现有方法通常将异构退化条件编码在共享的潜在空间中，其中退化相关线索与场景内容可能保持纠缠。我们将由此带来的挑战刻画为双重歧义：通道级调制中的语义歧义和复原响应中的空间歧义，这可能导致内容损坏和残余伪影。为了解决这个问题，我们提出了 DAR-Net，一个用于一体化图像复原的双重歧义矫正网络。DAR-Net 首先引入了一个退化原型表示（DAR）模块，通过单纯形约束的原型混合建模来构建结构化的退化状态。基于该状态，语义歧义矫正（SeAR）模块生成退化感知提示，以改善解码器中的通道级条件调节。空间歧义矫正（SpAR）模块进一步将退化感知特征和互补特征朝向正交响应子空间进行正则化，从而减少去除线索和保留线索之间的空间干扰。在标准一体化复原基准上的大量实验表明，DAR-Net 在三种退化和五种退化设置下均取得了最佳整体性能，相较于最强竞争对手，平均 PSNR 分别提升了 0.14 dB 和 0.34 dB；此外，它在 CDD-11 和 WeatherBench 上也展现了优越的性能。

## Abstract
All-in-one image restoration aims to handle diverse degradations within a unified framework. Existing methods commonly encode heterogeneous degradation conditions in a shared latent space, where degradation-related cues and scene content can remain entangled. We characterize the resulting challenge as dual ambiguity: semantic ambiguity in channel-wise modulation and spatial ambiguity in restoration responses, which can lead to content corruption and residual artifacts. To mitigate this issue, we propose DAR-Net, a Dual-Ambiguity Rectification Network for all-in-one image restoration. DAR-Net first introduces a Degradation Archetype Representation (DAR) module to construct a structured degradation state through simplex-constrained archetype mixture modeling. Based on this state, a Semantic Ambiguity Rectification (SeAR) module generates degradation-aware prompts to improve channel-wise conditioning in the decoder. A Spatial Ambiguity Rectification (SpAR) module further regularizes degradation-aware and complementary features toward orthogonal response subspaces, reducing spatial interference between removal and preservation cues. Extensive experiments on standard all-in-one restoration benchmarks show that DAR-Net achieves the best overall performance under both three-degradation and five-degradation settings, improving the average PSNR over the strongest competitor by 0.14 dB and 0.34 dB, respectively; it additionally shows superior performance on CDD-11 and WeatherBench.

*   **核心问题**：现有方法通常将不同退化类型的特征编码在共享的潜在空间中，这导致了**退化相关线索与场景内容特征的纠缠**。这种纠缠被作者归纳为“双重歧义”：
    *   **语义歧义**：通道维度上的特征纠缠，使得模型难以判断哪些通道负责编码退化信息，哪些负责内容信息，导致内容损坏。
    *   **空间歧义**：空间维度上的特征纠缠，使得复原响应在空间上缺乏选择性，导致退化残留或内容被误删。
*   **整体含义**：通过明确建模并解决这两种歧义，引导模型学习到更清晰的“去”与“留”的区分能力，从而在统一的框架下实现更高质量、更鲁棒的一体化图像复原。

### 2. 方法论

论文提出了一个名为 **DAR-Net** 的双重歧义矫正网络。其核心思想是构建一个结构化的退化表征，并利用它分别在通道和空间维度上解耦退化与内容信息。

**技术框架与关键组件**:

*   **基础架构**: 基于一个层级式U型Transformer的主干网络。
*   **退化原型表示模块**:
    *   **思想**: 将任何退化状态建模为一组可学习的退化原型在单纯形上的凸组合。
    *   **流程**:
        1.  使用轻量级卷积网络从输入图像提取退化敏感特征，并通过全局平均池化得到全局退化描述符`g`。
        2.  将`g`映射为一个系数向量`α`（`α = Softmax(Wg + b)`），`α`非负且和为1。
        3.  用系数向量`α`对一组可学习的退化原型矩阵`A`进行加权求和，得到结构化的**退化状态 `S_deg`** (`S_deg = Aα`)。该状态提供了关于当前退化的全局先验。

*   **语义歧义矫正模块**:
    *   **思想**: 利用退化状态`S_deg`来修正提示，以缓解通道维度上的语义纠缠。
    *   **组件与流程**:
        *   **原型引导的提示生成器**:
            1.  首先，根据输入特征动态加权组合一组可学习的提示张量，生成**基础提示 `F_p`**。
            2.  然后，将退化状态`S_deg`映射为一个**通道路由向量**。该向量通过与`F_p`进行通道级乘法（`F_dp = F_p ⊙ s`），增强与当前退化相关的通道，抑制无关通道，生成**退化感知提示 `F_dp`**。
            3.  在最深层解码阶段，通过残差减法从输入特征中减去`F_dp`，提取**互补的内容特征 `F_c`** (`F_c = F_in - F_dp`)。
        *   **退化感知提示集成器**:
            *   将退化感知提示`F_dp`和内容特征`F_c`(或下层特征)映射为查询 (Query)、键 (Key)和值 (Value)，并通过**通道注意力**机制将提示信息注入到解码器的特征调制过程中。

*   **空间歧义矫正模块**:
    *   **思想**: 通过对退化感知特征和内容特征施加正交性约束，促使它们的空间响应子空间相互正交，从而缓解空间纠缠。
    *   **核心组件——正交子空间矫正**:
        1.  将`F_dp`和`F_c`通过可学习的映射`Ω`变换到新空间，得到`F̃_dp`和`F̃_c`。
        2.  对两个特征的每个通道进行L2归一化，得到归一化后的空间响应矩阵`X_dp`和`X_c`。
        3.  通过最小化**正交子空间矫正损失 `L_OSR`** 来约束二者正交。该损失定义为`X_dp`和`X_c`的交叉格拉姆矩阵的Frobenius范数的平方：`L_OSR = ||X_dp * (X_c)^T||_F^2`。最小化此损失意味着抑制两个特征所有成对通道空间响应之间的相互作用。

*   **训练目标**: 总损失函数由像素级L1重建损失和`L_OSR`正则项组成：`L_total = L_rec + λ * L_OSR`。
