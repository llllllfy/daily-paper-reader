## 摘要
稀疏自编码器（SAEs）作为可解释性工具的广泛应用受到了SAE特征与模型行为之间不一致联系的限制。具有清晰激活描述的特征可能具有较弱或出乎意料的因果效应；引导可能因提示而异或与预期方向相反；基于激活的特征选择可能会遗漏产生所需输出变化的特征。先前的工作研究了模型内部的特征几何结构，即特征被计算之处。而我们研究的是由特征干预引起的模型逻辑值变化的几何结构。我们提出了特征效应几何分析（FEGA），这是一种无监督框架，能够在不同上下文中移除相同的活跃SAE特征，并分析由此产生的逻辑值变化云。在各类SAE变体中，一致的一维效应很少见：很少有特征表现得像可重复使用的方向。为了解释这种变化，我们区分了与静态信息（例如事实属性）相关的类似值的特征，和与上下文相关操作关联的类似指针的特征。类似值的特征更常展现出结构化的、低维的效应，尽管这些效应通常跨越多个方向。相比之下，类似指针的特征主要表现出扩散效应。我们的结果表明，一个特征可以是可解释的且在因果上相关，但却不提供一个稳定的引导方向。

## Abstract
The wide-scale use of sparse autoencoders (SAEs) as interpretability tools is limited by inconsistent links between SAE features and model behavior. Features with clear activation descriptions may have weak or unexpected causal effects; steering can vary across prompts or oppose the intended direction; and activation-based feature selection can miss features that produce the desired output change. Prior work has studied feature geometry inside the model, where features are computed. We instead study the geometry of changes in model logits caused by feature interventions. We introduce Feature-Effect Geometry Analysis (FEGA), an unsupervised framework that removes the same active SAE feature across contexts and analyzes the resulting cloud of logit changes. Across SAE variants, consistent one-dimensional effects are rare: few features behave like reusable directions. To interpret this variation, we distinguish value-like features, tied to static information such as factual attributes, from pointer-like features, associated with context-dependent operations. Value-like features more often exhibit structured, low-dimensional effects, although these effects typically span several directions. Pointer-like features, by contrast, predominantly exhibit diffuse effects. Our results show that a feature can be interpretable and causally relevant without providing a stable direction for steering.

## 1. 核心问题与整体含义
- **研究背景**：稀疏自编码器（SAE）被广泛用于大语言模型的可解释性，它将模型激活映射到稀疏的潜在空间，通常能产生比单个神经元更可解释的特征。  
- **核心矛盾**：尽管许多 SAE 特征具有清晰的激活描述，其下游因果效应却常常不一致。例如，特征引导的效果可能因提示而异，甚至与预期方向相反；看似语义明确的特征，其干预后对输出逻辑值（logits）的改变缺乏可预测性。  
- **整体含义**：本研究指出，SAE 特征的解释不应仅停留在“表示了什么”，更需考察“干预后在下游输出空间产生了怎样的几何变化”。作者提出，一个特征可以同时具有可解释性和因果重要性，却未必能提供稳定的、可复用的引导方向，这挑战了将 SAE 特征视为简单线性控制变量的常见假设。

## 2. 方法论：特征效应几何分析（FEGA）
- **核心思想**：FEGA 是一个无监督框架，它跨多个上下文移除同一个活跃的 SAE 特征，收集其在模型最终逻辑值上引起的差分变化，形成“效应云”，并通过一系列几何诊断对云的形状进行分类。
- **关键步骤与术语**：
  - **干预方式**：不直接比较原始激活，而是以 SAE 重建为基线。对于特征 \(j\)，将其编码清零后解码，得到重建 \(\hat{h}\)；与保留所有特征的重建 \(\bar{h}\) 分别通过冻结的模型尾部，计算逻辑值差分 \(\Delta = \phi(\hat{h}) - \phi(\bar{h})\)。
  - **效应云**：在有效上下文中，收集所有 \(\Delta\) 构成特征的下游逻辑值效应云 \(\mathcal{E}_{j,\text{logit}}\)。
  - **几何诊断谱系**（按优先级依次测试）：
    1. **有向射线**：所有效应是否指向同一方向，用均值非对角线相似度 \(C_{\text{ray}}\) 衡量。
    2. **轴或对跖结构**：若一维结构明显但方向存在正负两种符号，则为一根轴上的两端。
    3. **方向混合**：利用 von Mises–Fisher 混合模型检验是否存在多个相干的方向模式。
    4. **全局低维张成子空间**：效应方向是否落入一个低维（2,3,4,8 维）子空间，通过核矩阵的特征谱评估。
    5. **中心化残差谱**：若平均方向主导，则检验扣除均值后剩下的变化是否仍为低维。
  - **计算技巧**：为避免显式构建词汇量大小的 logit 向量，使用 pre-logit 效应向量与 unembedding 矩阵的 Gram 矩阵 \(G=W_U^\top W_U\) 来高效计算 logit 空间的内积和范数。
  - **特征角色划分**：作者借鉴编程语义中“值”与“指针”的比喻，将特征区分为**值类特征**（与静态事实知识相关，如国家属性）和**指针类特征**（与上下文相关的操作相关，如复制、规则遵循），并通过一系列任务分别筛选这两类特征。

## 3. 实验设计
- **基础模型与 SAE**：所有实验在 **Gemma-2-2B** 的第 **12 层残差流**上进行。对比了三种宽度均为 \(2^{16}\approx 65\text{k}\) 的 SAE 变体：**ReLU**、**TopK** 和 **Matryoshka Batch TopK**，均来自 SAEBench 基准套件。
- **任务频谱与特征筛选**：
  - **指针类任务**（上下文内学习，ICL）：
    - *Literal Sequence Copying (LSC)*：纯合成，复制前文出现的下一个词。
    - *Word Content (WC)*：合成词汇上基于提示的标签分类。
    - *PrOntoQA*：虚构谓词的规则完成。
    - *Token Translation (TT)*：结合提示内翻译格式与预训练词汇知识的混合任务。

## 6. 主要结论与发现
1.  **一致的有向效应极为罕见**：在所有任务和 SAE 变体中，极少数特征的效应云能坍缩为一个单一的、跨上下文不变的 logit 向量（有向射线）。
2.  **指针类特征效应弥漫**：与复制、绑定、规则应用等操作相关的指针类特征，其下游效应绝大多数是高维或弥漫的。这是因为它们协助的输出目标随上下文中的值而变化，无法形成固定的引导方向。
3.  **值类特征效应更结构化**：与事实属性相关的值类特征更常表现出低维的几何组织，但这种结构通常覆盖**多个输出方向**（如二维子空间），而非单一方向。
4.  **特征角色与几何结构的关联**：特征的因果角色（值 vs. 指针）与其下游效应的几何结构显著相关，证实了 FEGA 区分不同功能特征的有效性。
5.  **架构影响**：TopK 和 Matryoshka Batch TopK 在跨任务的特征复用程度上高于 ReLU SAE，但没有任何架构在所有任务上均产生最多的候选特征。

## 7. 优点
- **视角创新**：首次系统研究 SAE 特征在**下游输出空间**的效应几何，填补了从内部表示到行为效果之间的空白，将讨论从“特征表示什么”推进到“干预产生何种几何扰动”。
- **方法论严谨**：FEGA 框架提供了从效应云构建、多级几何诊断到稳定性验证的完整无监督分析流程，定义清晰且可复现。
- **实验设计微妙**：通过精心设计的任务频谱，清晰分离了值类与指针类特征，并采用因果消融+随机对照的方法确保了特征集的因果相关性，为几何分析提供了可靠前提。
- **工程实现巧妙**：利用 pre-logit Gram 矩阵避免了在高维词汇空间上直接操作，使分析在计算上可行。
- **结论具有冲击力**：直接挑战了“可解释特征即可稳定引导”的普遍假设，对 SAE 用于模型编辑和引导的实际应用提出了重要警示。

## 8. 不足与局限
- **模型与层位单一**：所有实验仅在 Gemma-2-2B 的第 12 层上进行。结论对更大模型、其他层或架构的泛化能力尚不明确。
- **任务设定的人工性**：所使用的任务多为结构化提示或合成任务，与自然语言的复杂、多步生成场景存在差距。指针类与值类特征在真实文本中的交互可能更复杂。
- **特征筛选与样本边界**：
  - 指针类特征的高门限筛选（90% 活跃度）可能漏掉一些重要但非高频率的特征。
  - FEGA 最多为每个特征保留 64 个有效上下文，样本量限制可能影响对弥漫效应的精细刻画。
  - 大量特征被标记为“未定义几何”或“效应证据不足”，基于已映射特征的分布所做结论无法代表全体特征。
- **输出空间的局限**：测量仅在最终的 logit 读出层进行，无法揭示效应在模型内部各层是如何从低维扰动逐渐扩散为高维词汇效应的。
- **缺乏行为验证闭环**：虽然观测了 logit 几何，但没有进一步验证这些几何分类与实际生成文本或控制任务成功率的直接关联。
