## 摘要
视觉基础模型越来越多地被重用为下游视觉识别的冻结主干，这使得参数高效自适应成为一个核心问题。基于提示的自适应方法，包括视觉提示微调（VPT），提供了一种轻量级的模型专业化方式，但其逐层行为仍未得到充分理解：性能对提示的深度、位置和任务分布敏感，并且在标准域内基准上的增益并不总能转化为稳健的泛化能力。我们认为，这一局限不仅仅是优化问题，而是逐层信息分配问题：现有的基于提示的方法缺乏对提示条件表示在深度上应保留、抑制和传播什么的原则性控制。受信息瓶颈原理的启发，我们提出了提示化信息瓶颈（PIB）框架，该框架规范了逐层的压缩-充分性权衡，并促进了更连贯的跨层信息路径。其核心思想是，有效的自适应应当是最小且充分的，即在浅层保留任务相关的局部证据，同时在深层逐步丢弃干扰因素和冗余细节。大量实验表明，PIB 在 34 个数据集上取得了强大的性能，在 FGVC 上达到 92.1%，HTA 上达到 93.01%，VTAB-1k 上达到 77.33%，而在主要设置中平均仅微调 0.35% 的参数。除了基准准确率，PIB 有助于解释提示容量缩放的非单调行为，减少捷径依赖，并在分布偏移和细粒度识别设置下提升鲁棒性。这些结果使 PIB 既是一种实用方法，也是适应冻结视觉基础模型的一种信息分配视角。我们的代码可在 https://github.com/itsnotacie/MM-26-PIB 获取。

## Abstract
Vision foundation models are increasingly reused as frozen backbones for downstream visual recognition, making parameter-efficient adaptation a central problem. Prompt-based adaptation, including Visual Prompt Tuning (VPT), provides a lightweight way to specialize these models, but its layer-wise behavior remains poorly understood: performance is sensitive to prompt depth, placement, and task distribution, and gains on standard in-domain benchmarks do not always translate into robust generalization. We argue that this limitation is not solely an optimization issue, but a layer-wise information allocation issue: existing prompt-based methods lack principled control over what prompt-conditioned representations should preserve, suppress, and propagate across depth. Inspired by the Information Bottleneck principle, we introduce Prompted Information Bottlenecks (PIB), a framework that regularizes layer-wise compression-sufficiency trade-offs and promotes a more coherent cross-layer information path. The key idea is that effective adaptation should be minimal yet sufficient, retaining task-relevant local evidence in earlier layers while progressively discarding nuisance factors and redundant details in deeper layers. Extensive experiments show that PIB achieves strong performance across 34 datasets, reaching 92.1% on FGVC, 93.01% on HTA, and 77.33% on VTAB-1k, while tuning only 0.35% parameters on average across the main settings. Beyond benchmark accuracy, PIB helps explain the non-monotonic behavior of prompt capacity scaling, reduces shortcut reliance, and improves robustness under distribution shift and fine-grained recognition settings. These results position PIB as both a practical method and an information-allocation perspective for adapting frozen vision foundation models. Our code is available at https://github.com/itsnotacie/MM-26-PIB

### **2. 论文提出的方法论 (核心思想、关键技术细节)**

本论文提出了一个名为**提示化信息瓶颈（Prompted Information Bottleneck, PIB）**的理论框架和训练方法，用以规范化提示自适应过程中的逐层信息分配。

*   **核心思想：最小且充分的信息路径 (Minimal-yet-Sufficient Path)**
    PIB 借鉴信息瓶颈（Information Bottleneck, IB）原则，将提示调优重新定义为塑造跨层信息路径的过程。目标是使每一层的 prompt 条件化表征都遵循“最小且充分”原则：**在压缩输入中与任务无关的冗余信息（`IX`）的同时，保留与任务标签（`Y`）相关的判别性信息**。这引导模型形成一条从保留局部证据到逐步语义抽象的、连贯的跨层精炼轨迹。

*   **关键技术细节与公式化设计**
    由于直接在高维空间中优化互信息难以实现，PIB 通过设计三个互补的、可微的代用损失（Surrogate Losses）来实现 IB 目标：
    1.  **逐层压缩目标 (Compression Surrogate)**：
        *   **目的**：抑制冗余或携带干扰（如纹理、背景）的特征维度，促使表征更紧凑。
        *   **实现**：对每一层的 `ℓ2` 归一化隐藏状态 `\tilde{H}_l`，计算其**经验相关矩阵** `C_l`。压缩损失为矩阵中非对角线元素能量的平方和。
        *   **公式思想**：`L^{(l)}_{comp} = \|C_l - I_d\|^2_{F, \text{off}}`。最小化此项会降低不同特征维度间的相关性，从而减少表示中的冗余。
    2.  **逐层充分性目标 (Sufficiency Surrogate)**：
        *   **目的**：防止过度压缩，确保每一层表征仍保留服务于最终分类的判别性语义结构。
        *   **实现**：基于小批量内的类别紧凑度与类间可分性。计算**类内散度** `S^{(l)}_{intra}` 和**类间散度** `S^{(l)}_{inter}`。
        *   **公式思想**：`L^{(l)}_{suff} = \frac{S^{(l)}_{intra}}{S^{(l)}_{inter} + \epsilon}`。最小化此项促使同一类别的样本在表示空间中更聚集，不同类别的中心距离更远。
    3.  **跨层路径正则化 (Cross-layer Path Regularization)**：
        *   **目的**：确保信息精炼过程沿深度方向是平滑渐进（Monotonically improving）的，避免表征质量在相邻层间剧烈波动或恶化。
        *   **实现**：为每一层定义一个综合了压缩与充分性的“质量分数” `q_l`。路径损失惩罚后续层分数劣于前一层的幅度。
        *   **公式思想**：`L_{path} = \sum_{l=1}^{L-1} \max(0, q_{l+1} - q_l - \delta_l)`。此项强制形成一条单调优化的跨层路径。

*   **可选模块：层感知路由 (Layer-aware Routing)**
    引入一个可学习的门控机制 `r_l \in [0, 1]`，允许不同层根据自身在主干网络中的角色，动态偏向压缩或充分性目标。浅层可以更侧重于保留证据（`1 - r_l` 权重更大），深层则可以更侧重于抑制冗余（`r_l` 权重更大），增加了灵活性。

*   **最终目标函数**
    将上述各项与标准任务损失（交叉熵）结合：
    `L_{total} = L_{task} + L_{PIB} + \eta L_{path}`
    整个训练过程保持预训练的 Transformer 模块冻结，仅优化提示参数、任务头以及可选的路由变量。

*   **新颖的理论视角**：从一个全新的“信息分配”高度，重新审视了提示调优的本质问题，为理解 PEFT 方法提供了深刻的洞察。

### **8. 不足与局限**

*   **代用损失的理论完备性**：PIB 使用的压缩与充分性损失仅是互信息 `I(H; X)` 和 `I(H; Y)` 的近似代用品，而非精确计算。这使其成为“信息启发式”而非严格意义上的 IB 实现，其性能优势可能与启发式目标设计有关，而非直接源于优化互信息。
*   **任务范围局限**：所有实验均围绕**分类任务**展开。对于目标检测、图像分割、图像生成或跨模态理解等更复杂的下游任务，当前基于类别可分性的充分性损失可能需要重新定义。
*   **超参数敏感性**：方法依赖多层损失间的平衡系数（`λ_l`, `γ_l`, `α_l`, `δ_l`）。虽然设计了自适应路由，但其性能可能仍对初始系数设置存在一定敏感性。
*   **路径正则化的强先验**：假设表征质量应沿深度平滑单调提升。对于一些需要跳跃连接或非单调信息流的特殊任务架构，这一先验可能过于严苛。
