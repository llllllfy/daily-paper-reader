## 摘要
多模态图像融合（MMIF）旨在将互补传感器数据整合为单一表示，在保留场景本真信息的同时消除环境干扰。现有方法大多依赖盲特征聚合，虽擅长信号累积，但难以区分本质内容与物理退化。我们提出SGPDFuse，通过基于预训练视觉基础模型构建的语义-物理参数化桥（SPPB）将输入映射为物理解耦的结构表示，利用本征变异原理将不变的场景属性与瞬态环境因素解耦。为了引导这种分解，我们引入语义对齐机制：通过余弦相似度将融合表示显式锚定到同一基础模型特征空间中的显著语义特征，以保留关键目标，同时通过Gram矩阵正则化强化物理纹理保真度，严格消除非自然伪影。大量实验表明，SGPDFuse在红外-可见光、多聚焦和多曝光基准上以单一架构取得了最先进的性能。

## Abstract
Multimodal image fusion (MMIF) aims to integrate complementary sensor data into a single representation that preserves intrinsic scene reality while eliminating environmental interferences. Most existing approaches rely on blind feature aggregation, which excels at signal accumulation but fails to distinguish essential content from physical degradations. We propose SGPDFuse, which bridges this gap by mapping inputs into a physics-disentangled structural representation via a Semantic-Physical Parametric Bridge (SPPB) built on pretrained vision foundation models, utilizing the Intrinsic-Variation principle to decouple invariant scene attributes from transient environmental factors. To guide this decomposition, we introduce a Semantic Alignment mechanism: we explicitly anchor the fused representation to salient semantic features in the same foundation model feature space via cosine similarity to preserve critical targets, while enforcing physical texture fidelity through Gram-matrix regularization to strictly eliminate unnatural artifacts. Extensive experiments demonstrate that SGPDFuse achieves state-of-the-art performance across infrared-visible, multi-focus, and multi-exposure benchmarks using a single architecture.

## 1. 论文的核心问题与整体含义

- **研究背景与动机**  
  多模态图像融合（MMIF）旨在将来自不同传感器的互补信息整合为单一图像，同时保留场景本真内容并抑制传感器特异的退化。典型任务包括红外-可见光融合（IVIF）、多曝光融合（MEF）和多聚焦融合（MFF）。

- **现有方法的根本缺陷**  
  当前大多数深度学习方法将融合视为**盲特征聚合**：通过加权求和或特征拼接最大化信息保留。然而，这类做法混淆了两类本质不同的信号成分：
  - **本征成分（Intrinsic）**：场景固有的物理属性，如真实温度、表面反射率、锐利纹理。
  - **变异成分（Variation）**：由环境或传感器引入的瞬态干扰，如热反射、光照变化、光学模糊。  
  这种混淆会导致鬼影热目标、曝光失真、散焦区域纹理丢失等伪影。

- **论文的核心思想**  
  作者从物理成像模型中提炼出统一结构：
  \[
  I = G(\Phi, \Psi)
  \]
  其中 \(\Phi\) 为本征分量，\(\Psi\) 为变异分量，\(G\) 为模态特定的物理混合过程。例如：
  - IVIF：\(L = \epsilon B(T) + (1-\epsilon)L_{env}\)（热辐射 + 环境反射）；
  - MEF：\(I = R \cdot L\)（反射率 × 光照）；
  - MFF：\(I = S \otimes K\)（清晰图像卷积模糊核）。

  因此，融合不应盲目聚合信号，而应先**解耦本征与变异**，仅融合本征分量。该论文提出的 SGPDFuse 正是基于这一“物理解耦”视角的统一框架，利用视觉基础模型的语义特征估计物理变异参数，实现跨任务的通用融合。

## 2. 论文提出的方法论

### 2.1 总体框架
SGPDFuse 采用**双分支编码器—物理解耦—物理引导融合—解码器**结构，整体流程如下：

1. **双分支特征提取**：共享编码器将源图像 \(I_A, I_B\) 分解为**基频（base）**和**细节（detail）**特征，分别对应低频能量和高频纹理。
2. **语义-物理参数桥（SPPB）**：利用 DINOv3 + LoRA 提取语义 token，预测每像素的**变异置信图 \(W\)**。
3. **本征-变异解耦**：根据 \(W\) 将特征分离为本征分量 \(\Phi\) 和变异分量 \(\Psi\)，变异分量被丢弃。
4. **物理引导融合**：仅对本征分量进行融合，基频层采用 SE 注意力加权，细节层采用 \(L_1\) 活动度选择。
5. **解码与损失约束**：解码得到融合图像，并通过重建对齐损失在 DINOv3 特征空间进行语义监督。

### 2.2 关键技术细节

#### （1）语义-物理参数桥（SPPB）
- **语义特征提取**：使用 DINOv3 ViT-S/16 作为语义骨干，通过 LoRA（秩 \(r=32\)）进行任务感知微调，提取空间语义 token \(Z^{(m)}\)。
- **材料库变异估计**：构建任务特定的材料库 \(\mathcal{M} = \{(\varphi_k, e_k)\}_{k=1}^{K}\)，其中 \(\varphi_k\) 为物理测量值（如红外发射率、曝光最优性、聚焦概率），\(e_k\) 为 DINOv3 原型嵌入。通过软最近邻回归估计每像素的物理参数锚点：
  \[
  \hat{\varphi}_{ij} = \sum_k \text{softmax}_k\left(-\frac{\|Z_{ij} - e_k\|}{\tau}\right) \varphi_k
  \]
  然后与编码器特征聚合，经 sigmoid 得到变异置信图：
  \[
  W_{ij} = \sigma\left(f_\theta(F_A, F_B) + g(\hat{\varphi}_{ij})\right)
  \]
- **互补源分配**：\(W_A = W\)，\(W_B = 1-W\)，对应物理上的互补关系（如红外高发射率处，可见光以反射为主）。

#### （2）本征-变异解耦
- 利用 \(W\) 对特征进行加权投影，并通过可学习残差网络 \(R_\Phi, R_\Psi\) 修正非正交性：
  \[
  F^\Phi_m = W_m \odot F_m + R_\Phi(W_m \odot F_m)
  \]
  \[
  F^\Psi_m = (1-W_m) \odot F_m + R_\Psi((1-W_m) \odot F_m)
  \]
- 施加一致性约束 \(F^\Phi_m + F^\Psi_m \approx F_m\)，防止信息丢失或重复。
- 解耦后，变异分量 \(\Psi\) 被直接丢弃，从构造上消除环境干扰。

#### （3）物理引导融合
- **基频融合**：使用 SE 通道注意力并结合 \(W\) 的置信度加权，让高置信度源主导基频层。
- **细节融合**：基于 \(L_1\) 活动度衡量局部锐度，选择更清晰的模态。
- 该不对称设计源于本征内容在基频和细节层具有不同的物理特性。

#### （4）损失函数
总损失为：
\[
\mathcal{L}_{total} = \mathcal{L}_{IG} + \lambda_{decomp}\mathcal{L}_{decomp} + \lambda_{RecA}\mathcal{L}_{RecA} + \lambda_{tv}\mathcal{L}_{tv}
\]
- **\(\mathcal{L}_{IG}\)**：强度与梯度保真，使融合图像逼近源图像的逐像素最大值和最大梯度。
- **\(\mathcal{L}_{decomp}\)**：包含基频互相关、细节互补性以及解耦一致性约束。
- **\(\mathcal{L}_{tv}\)**：对 \(W\) 施加总变分正则，促进空间平滑。
- **\(\mathcal{L}_{RecA}\)（重建对齐损失）**：在 DINOv3 特征空间内，通过余弦相似度对齐融合图像与源图像的语义内容，并通过 Gram 矩阵匹配纹理风格，兼顾语义保真与物理一致性。

训练采用两阶段课程：先进行重建预训练建立稳定特征空间，再进行端到端融合微调。

## 7. 优点

- **视角新颖**：将多模态融合问题从“信号聚合”重新表述为“物理解

耦”，并基于统一物理成像模型 \(I=G(\Phi,\Psi)\) 进行形式化，理论动机清晰、可解释性强，避免了以往方法“黑箱式”特征聚合的局限。

- **统一框架设计**：SGPDFuse 在单一架构下同时处理 IVIF、MEF、MFF 三类任务，通过材料库和变异置信图自适应调整解耦策略，减少了任务特定模块的重复设计。

- **实验验证较为全面**：不仅在多个公开数据集上进行了融合质量评估，还通过目标检测和语义分割验证了融合结果对高层感知任务的增益，消融实验也较系统地分析了关键组件的贡献。

SGPDFuse 是一篇理论视角新颖、方法设计较为完整的工作。它从物理成像模型出发，将多模态融合从“盲特征聚合”推进到“物理解耦”，并借助 DINOv3 语义特征和材料库实现跨任务统一建模，在 IVIF、MEF、MFF 及下游检测分割任务上均取得了具有竞争力的结果。尽管存在计算开销较大、材料库细节不足、统计验证有限等问题，但其核心思想——利用基础模型语义先验估计物理变异参数并显式解耦本征与变异——为多模态图像融合提供了新的研究范式，具有较强的启发意义和后续拓展空间。
