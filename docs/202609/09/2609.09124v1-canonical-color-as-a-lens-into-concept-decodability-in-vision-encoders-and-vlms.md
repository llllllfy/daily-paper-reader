## 摘要
视觉编码器为视觉语言模型构建图像输入的表示。这种表示包含多少概念信息而非直接可见信息？我们以规范颜色作为受控测试案例，探究视觉编码器是否使规范颜色信息线性可访问，即使从输入图像中移除了颜色。我们构建了一个具有规范颜色的对象数据集，并使用彩色和灰度图像探测视觉编码器的颜色和对象身份。我们发现规范颜色仍可从灰度图像中解码，并且与预测的对象身份相关联，这表明存在概念性联系。将这一分析扩展到完整的 VLM，我们发现 VLM 后训练对视觉编码器中的颜色可解码性可能产生令人惊讶的巨大影响。总体而言，规范颜色提供了一种有用的可控透镜，用于追踪视觉编码器和 VLM 中对象级别的概念语义信息。

## Abstract
Visual encoders construct a representation of the image input for Vision-Language models. How much conceptual, as opposed to immediately visible, information does this representation contain? We use canonical color as a controlled test case to ask whether vision encoders make canonical-color information linearly accessible, even when color is removed from the input image. We construct a dataset of objects with canonical colors, and probe vision encoders for both color and object identity using color and grayscale images. We find that canonical color remains decodable from grayscale images, and is tied to predicted object identity, indicating a conceptual link. Extending this analysis to full VLMs, we find that VLM post-training can have a surprisingly large effect on color decodability in the vision encoder. Overall, canonical color provides a usefully controllable lens for tracing object-level conceptual semantic information in vision encoders and VLMs.

## 6. 主要结论与发现

- **规范颜色在灰度图像下仍可线性解码**：所有五种编码器均显著高于多数类基线（约 14%），表明表示中包含超越可见颜色的概念性颜色信息。
- **残余信号更符合规范颜色而非表面颜色**：在 Visual-CounterFact 上，实际颜色探测接近多数类基线，而规范颜色探测在原图和反事实图上均保持较高且趋势一致。
- **与对象类别识别相关但不完全决定**：颜色探测与对象识别在层间趋势上呈强正相关（Spearman 0.60–0.90），但颜色线索并非完全由对象识别准确率决定；“预测对象颜色一致性”在后期层达到 55–65%，说明颜色预测常与模型自身的对象预测一致，但远非天花板。
- **VLM 后训练影响具有模型依赖性**：
  - CLIP→Molmo 和 CLIP→mPLUG-Owl：后训练视觉塔的颜色与对象线性可解码性下降（对象识别降幅尤其大）。
  - SigLIP→PaliGemma：后训练视觉塔基本保持原有 SigLIP 模式，变化很小。
- **信息在视觉接口或 decoder 侧重新出现**：在 Molmo 和 mPLUG-Owl 中，颜色和对象信息虽在独立视觉塔中减弱，但在 decoder 视觉 token 状态中恢复到接近原 CLIP 水平；在 mPLUG-Owl 中，主要提升发生在 Q-Former 视觉抽象器输出处。整体符合**表示重格式化（reformatting）**而非信息移除。
- **提示级行为混杂**：最终回答不能单纯反映视觉感知，VLM 在灰度图像上的颜色回答依赖对象先验与输出格式偏好；decoder 视觉 token 探测比行为输出更清晰地展示信息可解码性。
