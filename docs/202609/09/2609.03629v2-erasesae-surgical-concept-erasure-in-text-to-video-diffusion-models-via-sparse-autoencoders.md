## 摘要
文本到视频（T2V）扩散模型的最新进展展示了卓越的生成能力，但它们对松散整理训练数据的依赖引发了紧迫的安全与版权问题。概念擦除通过从预训练模型中移除不需要的语义、同时保留其余概念，提供了一种原则性的补救方法。然而，现有方法通常在粗粒度上操作，与概念表征的细粒度、分布式特性不一致，导致擦除不完整或生成质量下降。我们认为精准擦除从根本上需要在单义特征层面进行干预，其中每个单元编码单个可解释概念。为此，我们提出 EraseSAE，一个新颖框架，利用稀疏自编码器通过原则性的“分解-归因-擦除”流程在基于 DiT 的 T2V 扩散模型中实现精准概念擦除。我们首先引入分区卷积稀疏自编码器，将密集的时空激活分解为解耦、可解释的稀疏特征，同时保持时空一致性。然后，对比归因机制对比配对提示的激活，以隔离概念特定的特征核。在推理时，从识别出的核导出的逐时间步时空掩码将擦除限制在目标概念活跃的区域，保持无关内容完好。跨多种扩散模型和概念擦除任务的大量实验表明，EraseSAE 以最小的质量下降实现了精确且鲁棒的概念移除，显著优于现有最先进方法。代码可在 https://github.com/HiDream-ai/EraseSAE 获取。

## Abstract
Recent advances in text-to-video (T2V) diffusion models have demonstrated remarkable generative capabilities, yet their reliance on loosely curated training data raises pressing safety and copyright concerns. Concept erasure offers a principled remedy by removing unwanted semantics from pretrained models while preserving remaining concepts. However, existing approaches typically operate at a coarse granularity misaligned with the fine-grained, distributed nature of concept representations, leading to incomplete removal or degraded generation quality. We argue that surgical erasure fundamentally requires intervention at the level of monosemantic features, where each unit encodes a single interpretable concept. To this end, we propose EraseSAE, a novel framework that leverages sparse autoencoders to achieve surgical concept erasure in DiT-based T2V diffusion models via a principled decompose-attribute-erase pipeline. We first introduce the Partitioned Convolutional Sparse Autoencoder, which decomposes dense spatiotemporal activations into disentangled, interpretable sparse features while preserving spatiotemporal coherence. A contrastive attribution mechanism then contrasts activations from paired prompts to isolate concept-specific feature kernels. At inference, timestep-resolved spatiotemporal masks derived from the identified kernels confine erasure to regions where the target concept is active, leaving unrelated content intact. Extensive experiments across diverse diffusion models and concept erasure tasks demonstrate that EraseSAE achieves precise and robust concept removal with minimal quality degradation, substantially outperforming state-of-the-art methods. The code is available at https://github.com/HiDream-ai/EraseSAE.

  - **训练免微调方法**（如负提示、SAFREE）只在推理表层抑制概念，底层表征仍保留，容易被对抗提示绕过。

  - 现有方法普遍**缺乏时空局部性**：即使目标概念只出现在局部空间区域或某几帧，也往往全局干预，造成背景和无关内容退化。
- **整体含义**：论文认为精准概念擦除必须在**单义特征（monosemantic feature）**层面进行，即每个可解释特征单元只对应一个概念。为此提出 **EraseSAE**，首次将稀疏自编码器（SAE）用于 T2V 扩散模型的概念擦除，实现“外科手术式”概念移除。

## 2. 方法论

EraseSAE 采用 **decompose–attribute–erase** 三阶段流程。

### 2.1 Decompose：分区卷积稀疏自编码器（PConvSAE）

- **目的**：将 DiT 模型中间层的密集时空激活分解为可解释、解耦的稀疏特征，同时保持空间结构和时间连续性。
- **架构设计**：
  - 针对视频激活张量，将时间维度折叠到 batch 维，使用 **2D 卷积** 代替线性投影，避免展平破坏时空拓扑。
  - 潜在空间划分为两个互补分支：
    - **Context Branch**：编码与概念无关的场景上下文，如背景、光照、运动等。
    - **Concept Branch**：仅编码目标概念相关特征，并进一步在通道维度划分为多个**互斥子空间**，每个子空间对应一个目标概念。
  - 编码与解码过程：
    - 两个分支分别用独立的卷积编码器得到潜在表示 \(z_{ctx}\)、\(z_{cpt}\)。
    - 采用 **Spatial-Aware Local Activation**：对每个通道取空间峰值，选择 Top-K 最活跃通道，经 ReLU 激活，形成空间连贯的稀疏特征。
    - 解码后通过加法叠加重建：\(X_{recon} = W_{ctx}^{dec} * f_{ctx} + W_{cpt}^{dec} * f_{cpt} + b_{dec}\)。
- **训练目标**：
  - 利用扩散模型自身的 **cross-attention 图** 生成目标区域掩码 \(M_{tgt}\) 和背景掩码 \(M_{bg}\)，无需外部标注。
  - 五个损失项：
    1. **Context Reconstruction Loss \(L_{ctx}\)**：约束 Context Branch 重建背景、抑制目标区域。
    2. **Concept Reconstruction Loss \(L_{cpt}\)**：约束 Concept Branch 负责恢复目标区域语义。
    3. **Identity Leakage Penalty \(L_{leak}\)**：限制概念核只在指定概念/区域激活，避免语义泄漏。
    4. **Temporal Consistency Loss \(L_{temp}\)**：惩罚 Context Branch 相邻帧激活波动，减少闪烁。
    5. **Auxiliary Loss \(L_{aux}\)**：唤醒死亡潜在特征，提高字典利用率。

### 2.2 Attribute：对比归因机制

- 通过**一次性离线**流程锁定与目标概念高度相关的特征核。
- **构建正负样本**：正样本为包含目标概念的提示；负样本包括纯背景样本和其他概念的样本。
- **硬负基线**：
  \[
  \mu_{base} = \max\left(\mu_{bg}, \max_{j \ne i} \mu_{c_j}\right)
  \]
  即背景激活与所有其他概念激活的逐元素最大值。
- **对比 log-ratio 评分**：
  \[
  S_{attr} = \mu_{c_i} \odot \max\left(0, \log\frac{\mu_{c_i}+\epsilon}{\mu_{base}+\epsilon}\right) \odot M_{stable}
  \]
  - 乘以 \(\mu_{c_i}\) 强调高激活核；\(M_{stable}\) 过滤时间不稳定核。
  - 选取 Top-K 核，并与 PConvSAE 预分配的概念分区交集，得到锁定核 \(K_{tgt}\)。

### 2.3 Erase：动态时空掩码与空间调制 CFG

- **动态掩码生成**：
  - 在每个去噪时间步，计算 Context Branch 聚合激活的补集，得到前景掩码 \(M_{fg}\)。
  - 同时用锁定核 \(K_{tgt}\) 的 Concept Branch 激活得到目标概念掩码 \(M_{cpt}\)。
  - 最终干预掩码：
    \[
    M_t = \text{Norm}(M_{fg}) \odot \text{Norm}(M_{cpt})
    \]
    经阈值二值化。
- **空间调制 Classifier-Free Guidance（SM-CFG）**：
  \[
  \hat{\epsilon}_\theta(x_t) = \epsilon_\theta(x_t, c_{pos}) - s \cdot \left(\epsilon_\theta(x_t, c_{pos}) - \epsilon_\theta(x_t, c_{neg})\right) \odot M_t
  \]
  - 仅在掩码区域施加负向引导，其余区域保留原始正向预测，避免背景和无关内容受损。
