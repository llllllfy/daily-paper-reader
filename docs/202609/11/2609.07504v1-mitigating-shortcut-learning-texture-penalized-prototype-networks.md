## 摘要
标准卷积神经网络（CNNs）由于强烈的归纳纹理偏置优先处理局部高频模式而忽视全局结构形状，导致性能严重下降。这种依赖在纹理变化或环境影响下导致自信的错误分类。为解决这一缺陷，本研究提出了纹理惩罚原型网络（TPPN），一种新颖的架构框架，无需依赖资源密集的增强数据集即可改变这种固有偏置。具体而言，纹理惩罚分支（TPB）施加惩罚以抑制局部纹理代理的提取，迫使网络主干丢弃高频线索，提取纯化的、偏重形状的表示。通过在源自最终卷积特征的基于原型的超球面内评估相似性，该方法施加严格的几何约束，将物体视为基本组成部分的组合，以实现稳健分类。在纹理-形状线索冲突数据集和合成噪声基准上的评估表明，这种结构化解耦具有更强的形状偏置。所提出的框架将基线ResNet-50的固有纹理偏置从55.11%降至29.73%，超越了现成的视觉Transformer（ViT-B/16）的纹理抑制能力。此外，该方法在线索冲突条件下表现出稳健的泛化能力，在遇到分布外（OOD）形状时抵抗纹理捷径学习。该模型在增强扰动下保持更强的形状准确性。在干净验证数据上，该架构的准确率仅下降0.90个百分点。这为CNN纹理偏置提供了一种结构化且高效的解决方案。

## Abstract
Standard Convolutional Neural Networks (CNNs) exhibit severe performance degradation due to a strong inductive texture bias that prioritizes local, high-frequency patterns over global structural shapes. This dependency causes confident misclassifications during textural changes or environmental effects. To address this flaw, this study introduces the Texture-Penalized Prototype Network (TPPN), a novel architectural framework that shifts this inherent bias without depending on resource-intensive augmented datasets. Specifically, a Texture-Penalization Branch (TPB) imposes a penalty to suppress the extraction of local texture proxies, forcing the network backbone to discard high-frequency cues and extract purified, shape-biased representations. By evaluating similarities within a prototype-based hypersphere derived from the final convolutional features, the approach enforces strict geometric constraints, treating objects as compositions of essential parts to achieve robust classification. Evaluations on texture-shape cue-conflict datasets and synthetic noise benchmarks demonstrate the stronger shape bias of this structural disentanglement. The proposed framework reduces the inherent texture bias of a baseline ResNet-50 from 55.11% to 29.73%, surpassing the texture-suppression capabilities of an off-the-shelf Vision Transformer (ViT-B/16). Furthermore, the approach demonstrates robust generalization under cue-conflict conditions, resisting textural shortcut learning when encountering Out-of-Distribution (OOD) shapes. The model maintains stronger shape accuracy against elevated perturbations. On clean validation data, the architecture incurs a minimal drop in accuracy of 0.90 percentage points. This provides a structural, efficient solution to CNN texture bias.

# 《Mitigating Shortcut Learning: Texture-Penalized Prototype Networks》论文总结

## 1. 论文的核心问题与整体含义

- **研究背景**：标准卷积神经网络（CNNs）在图像识别中表现出强烈的**纹理偏置（texture bias）**，即更依赖局部高频纹理/表面统计信息，而不是全局几何形状。这种归纳偏置在纹理变化、环境干扰或“纹理-形状冲突”条件下容易导致自信的错误分类。
- **核心问题**：CNN 的纹理捷径学习（shortcut learning）限制了其在分布外（OOD）或受干扰场景中的鲁棒性；现有缓解方法存在代价高、计算开销大或降低干净数据性能等问题。
- **整体含义**：论文提出一种无需昂贵风格化增强数据集、可在标准 CNN 骨干上实现结构化纠偏的框架 **TPPN（Texture-Penalized Prototype Network）**，旨在让 CNN 具备接近甚至超过 ViT 的形状偏置与纹理抑制能力，同时保持干净分布上的分类性能。

## 2. 论文提出的方法论

- **整体架构**：TPPN 以预训练 ResNet-50 为骨干，从最深层卷积阶段 Layer 4（l4）提取高层语义特征；特征经过投影后进入“原型超球面”进行空间相似度匹配；同时引入一个**纹理惩罚分支（Texture-Penalization Branch, TPB）**，利用梯度反转层（GRL）主动抑制高频纹理特征的提取。
- **深度语义特征提取**：
  - 输入图像经过 ResNet-50 骨干，取出 Layer 4 的中间特征图 \(F_4 \in \mathbb{R}^{C_{in}\times H\times W}\)。
  - 通过 1×1 卷积 + BatchNorm + ReLU 投影，得到降维空间特征 \(Z_4 \in \mathbb{R}^{d\times H\times W}\)，文中 \(d=64\)。
- **超球面原型匹配**：
  - 维护可学习原型张量 \(W \in \mathbb{R}^{(c\times m)\times d}\)，其中 \(c\) 为类别数，\(m=5\) 为每类原型数量，用于捕获类内几何变化。
  - 将空间特征 \(Z_4\) 和原型 \(W\) 分别进行 L2 归一化到单位超球面，使用余弦相似度计算原始相似度矩阵 \(S_{raw} = \hat{Z}_4 \cdot \hat{W}\)。
- **动态 50% 空间池化**：
  - 为减少背景和空间噪声对几何信号的稀释，对 \(S_{raw}\) 在空间维度进行降序排序，保留前 50% 的相似度 token 做平均池化。
  - 保留 token 数 \(K = \max(1, \lfloor 0.5 \times H \times W \rfloor)\)。
- **纹理惩罚分支（TPB）**：
  - 训练时，每个输入图像随机施加 4 类高频纹理代理之一：**clean（无增强）、高斯模糊、斑点噪声、颜色抖动**，形成 4 分类纹理任务。
  - 对未投影的 l4 特征做自适应平均池化，然后经过 **GRL** 和 MLP 纹理头预测纹理代理类型。
  - 前向时 GRL 为恒等映射；反向时梯度乘以负标量 \(-\lambda_{Adv}\)，使骨干最大化纹理分类误差，从而**惩罚骨干提取高频纹理线索**，迫使其学习形状偏置表示。
- **温度缩放与推理头**：
  - 汇总后的相似度矩阵通过可学习温度参数 \(\tau\) 缩放，使用 softplus 加下限 \( \tau_{floor}=0.02 \) 保证数值稳定。
  - 使用 **bias-free 线性层** 将相似度映射为形状分类 logits；目标类原型连接初始化为 1.0，非目标类初始化为 -0.1（类似 imprinting weights）。
- **复合损失函数**：
  \[
  L_{Total} = \lambda_{CE} L_{CE} + \lambda_{Pull} L_{Pull} + \lambda_{Div} L_{Div} + \lambda_{Adv} L_{Adv}
  \]
  - \(L_{CE}\)：形状分类交叉熵。
  - \(L_{Pull}\)：基于 InfoNCE 的对比拉近损失，使用动态 dropout 掩蔽低于阈值的正样本原型，强制利用所有原型；对最佳正原型计算 softmax 对比损失。
  - \(L_{Div}\)：类内不同原型之间的正交性损失，防止原型坍缩。
  - \(L_{Adv}\)：纹理分类交叉熵，经 GRL 反向惩罚。
  - 权重：\(\lambda_{CE}=1.0, \lambda_{Pull}=0.5, \lambda_{Div}=0.75\)；\(\lambda_{Adv}\) 按 sigmoid 调度从 0.0 逐渐增加到 1.0，避免早期训练不稳定。

## 3. 实验设计

- **数据集与场景**：
  - **训练集**：从 ImageNet 选取的 **10 类平衡子集**，共 20,000 张图像（每类 2,000 张），类别为：飞机、熊、自行车、鸟、船、瓶子、汽车、猫、椅子、时钟。
  - **干净验证集**：从 ImageNet 验证集中取 1,600 张未扰动 ID 图像（每类 100–200 张）。
  - **Cue-Conflict 数据集**：Geirhos 等人的纹理-形状冲突数据集，图像包含相互矛盾的形状与纹理（如猫的形状 + 大象的纹理）。过滤掉形状和纹理类别相同的图像后，保留 1,050 张：
    - 450 张：ID 形状 + ID 纹理；
    - 300 张：ID 形状 + OOD 纹理；
    - 300 张：OOD 形状 + ID 纹理。
  - **OOD 类别**：6 个未在训练中出现的类别：狗、大象、键盘、刀、烤箱、卡车。
  - **扰动评估**：对过滤后的 cue-conflict 图像施加不同等级的斑点噪声 \(\eta \in \{0\%, 25\%, 50\%, 75\%\}\)，测试形状鲁棒性。
- **评价指标**：
  - **干净验证**：Top-1、Top-3 准确率。
  - **诱导偏置评估**：
    - Shape Accuracy (ID Texture)：ID 形状 + 冲突 ID 纹理时，预测形状正确的比例。
    - Texture Bias：预测与冲突纹理一致的比例。
    - Shape Accuracy (OOD Texture)：ID 形状 + OOD 纹理时的形状准确率。
    - Fooled by Texture（纹理欺骗脆弱性）：模型被熟悉纹理欺骗、忽略 OOD 形状的比例。
- **对比方法**：
  - **ResNet-50 基线**（在 10 类 ID 上训练）。
  - **ResNet-50 + TPB**：仅加入纹理惩罚分支，验证 TPB 单独作用。
  - **TPPN（w/o TPB）**：TPPN 消融模型，仅用原型推理但不加 TPB。
  - **TPPN（Final）**：完整模型。
  - **外部预训练基准**：ImageNet-1K 预训练的 VGG-16 和 ViT-B/16，通过将 1,000 类映射到 10 个粗粒度类别进行零样本评估。

## 6. 论文的主要结论与发现

- **干净数据性能保持**：TPPN 在干净 ImageNet 验证子集上 Top-1 为 \(98.16\% \pm 0.20\%\)，相比 ResNet-50 baseline 的 99.06%，仅下降 **0.90 个百分点**，表明纹理惩罚并未破坏自然分布上的分类能力。
- **纹理偏置显著降低**：TPPN 将 ResNet-50 的纹理偏置从 55.11% 降至 **29.73%**，优于 ViT-B/16 的 39.78%。
- **纹理欺骗抵抗增强**：在 OOD 形状 + 熟悉 ID 纹理场景中，TPPN 的“被纹理欺骗率”从 ResNet-50 的 70.33% 降至 **40.47%**，优于 ViT-B/16 的 54.67%。
- **OOD 纹理下的形状保持**：TPPN 对 ID 形状 + OOD 纹理的形状准确率达到 **30.13%**，高于 ResNet-50 的 22.00%。
- **扰动鲁棒性**：在 50% 噪声下，TPPN 形状准确率为 \(47.24\% \pm 1.06\%\)，高于 ResNet-50 baseline 的 40.89% 和 ResNet-50+TPB 的 42.44%；在极端 75% 噪声下达到 \(48.13\% \pm 0.94\%\)，超过 ViT-B/16 的 45.78%。
- **结构协同效应**：消融显示，TPPB 单独使用对 ID 形状准确率提升有限（19.11%），原型网络单独使用纹理欺骗率仍高达约 73.40%；**两者结合**才显著提高形状偏置与纹理鲁棒性。

## 7. 优点

- **无需风格化数据集**：通过在线扰动 + GRL 惩罚机制实现纹理抑制，避免使用 SIN 等昂贵外部数据集，训练成本相对较低。
- **结构高效**：基于标准 ResNet-50 改造，保持 CNN 的实时推理优势，但实现了接近甚至超过 ViT 的纹理-形状解耦能力。
- **清晰的消融分析**：分别验证 TPB 和原型结构的作用，有效证明两者协同价值。
- **指标丰富**：使用 shape accuracy、texture bias、fooled by texture 等多维度指标，较全面刻画形状-纹理偏置。
- **保持干净性能**：在提升鲁棒性的同时，干净数据准确率仅损失 0.90 个百分点，优于许多以牺牲标准性能为代价的纠偏方法。
- **多随机种子结果**：TPPN 关键指标报告均值 ± 标准差，增强结果可信度。

## 8. 不足与局限

- **数据集规模有限**：仅在 10 类 ImageNet 子集上训练验证，类别覆盖少，难以证明在大规模图像分类任务上的泛化能力。
